# 拼豆工作台领域词汇

这些术语区分作品设计、物理制作和品牌颜色，避免把不同尺寸的图纸与物理板混为一谈。

## Language

**项目（Project）**：一份可继续编辑和制作的拼豆作品，包含设计、所用色板和制作进度。
_Avoid_：把单块物理板称为项目。

**豆格（Cell）**：作品中可放置一颗豆的位置，以作品整体为坐标参照。
_Avoid_：像素点（谈及实体制作时）。

**空格（Empty cell）**：不放置豆的豆格，与放置白色豆的格子不同。
_Avoid_：白底。

**物理板（Pegboard）**：制作时承载豆子的拼接板，作品可跨越多块物理板。
_Avoid_：画布、作品尺寸。

**色板（Palette）**：某品牌、系列或自定义来源的一组可选颜色。
_Avoid_：跨品牌通用色卡。

**色号（Color ID）**：在指定色板内识别一种豆的标识；颜色看起来相同不代表色号可以互换。
_Avoid_：RGB 值。

**制作进度（Assembly progress）**：记录哪些豆格已经完成摆放的状态。
_Avoid_：保存状态。

**用量（Usage）**：设计中各色号所需的豆数，不包含额外损耗备料。
_Avoid_：采购数量。
