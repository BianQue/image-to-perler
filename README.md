# Image to Perler · 拼豆工坊

**把喜欢的图片，变成可以编辑、预览和保存的拼豆图纸。**

拼豆工坊是一款开源、本地运行的图片转拼豆工具。你可以导入图片，选择品牌色板和图纸尺寸，生成拼豆图案，再通过画笔、选区和填充工具修整细节，查看材料用量，并导出图纸用于制作。

工作台构建后只有一个 HTML 文件，可直接在浏览器中离线打开。图片处理和编辑均在本机完成，无需注册账号，也不需要上传图片到服务器。

[English](README_EN.md) · [使用与开发说明](docs/development.md) · [色板来源](docs/palette-provenance.md) · [验收记录](docs/implementation-review.md)

## 项目介绍

从图片到实际拼豆，通常还需要调整颜色、修整轮廓、统计用量，并保存制作进度。拼豆工坊把这些步骤放在同一个工作台中，让生成的图纸能够继续修改和使用。

它适合：

- **拼豆爱好者**：把像素画、插画或照片转成图纸，按需修整后制作。
- **图纸创作者**：编辑局部图案、更换品牌色板，输出图纸和用量清单。
- **开发者与 AI 工具用户**：基于开源代码扩展功能，或通过 Trae Skill 辅助制作图纸。

普通照片可以直接缩放减色，但不会自动变成精修像素画，也不包含通用抠图。轮廓清晰、背景简单的图片通常更容易得到可用结果。

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 图片转图纸 | 设置宽高、品牌色板和最大颜色数，将图片转换为豆格 |
| 透明区域处理 | 透明格表示不放豆，不透明白色保留为有效豆色 |
| 基础编辑 | 画笔、橡皮、填充、吸色、同色替换、Shift 直线 |
| 选区编辑 | 矩形与套索选区，支持移动、填充和删除 |
| 图纸调整 | 水平/垂直翻转、90° 旋转、调整画布尺寸、去孤点 |
| 色板映射 | 将现有图案按 RGB 最近色映射至另一套色板 |
| 制作辅助 | 显示色号、颜色筛选、用量统计和逐格完成标记 |
| 3D 预览与编辑 | 旋转、缩放查看立体豆格，并在三维视图中编辑 |
| 熔豆外观预览 | 调整豆孔、厚度和外径，观察近似熨烫外观 |
| 保存与导出 | 项目 JSON、带项目的离线 HTML、PNG、用量 CSV 和打印 |
| 撤销与恢复 | 撤销/重做，以及主动恢复本机草稿 |

选区创建和移动在二维视图中操作。熔豆预览是外观模拟，不预测实际温度、熨烫时间或材料融合效果。

## 快速开始

安装 **Node.js 24**，然后运行：

```bash
git clone https://github.com/BianQue/image-to-perler.git
cd image-to-perler
npm ci
npm run build
```

构建完成后，直接用浏览器打开 `dist/index.html`。

安装依赖时需要网络；构建后的工作台可以离线使用。3D 功能需要浏览器支持 WebGL。

## 从图片开始制作

1. 设置图纸宽度、高度、品牌色板和最大颜色数。
2. 点击「导入图片并转换」，选择本地图片。
3. 使用画笔、填充或选区工具修整图案。
4. 查看颜色用量，按需切换到 3D 视图检查效果。
5. 保存项目 JSON，并导出 PNG、CSV 或离线 HTML。
6. 实际制作时，用「制作标记」记录已完成的豆格。

图片会缩放到设置的宽高。为避免拉伸，建议按原图比例设置尺寸，或先裁剪图片。

## 保存作品

**建议把项目 JSON 作为长期存档。**

项目文件保存图纸尺寸、色板、每格色号、空格和制作进度，之后可以重新打开继续编辑。

- **项目 JSON**：用于保存与继续编辑。
- **离线 HTML**：包含工作台和当前项目快照，方便在其他电脑打开。
- **PNG**：用于查看、分享或打印图纸。
- **CSV**：用于核对色号与用豆数量。
- **本机草稿**：用于临时恢复，不替代已下载的项目文件。

物理板尺寸用于显示分区，不改变图案的全局豆格坐标。

## 品牌色板与颜色说明

当前内置来自 `beadcolors` 的 **12 套色板，共 1,315 个色号**，涵盖 Artkal、Hama、Perler、Nabbi 和 Yant 的相关系列。

这些数据是社区整理的屏幕色值，不代表厂商官方认证。屏幕显示、实体豆批次和熨烫效果都可能影响最终观感，购买材料前请核对实体色卡。

你可以导入自己整理或已获得授权的 JSON 色板。

色板来源、许可证和导入格式见[色板来源说明](docs/palette-provenance.md)。

## 在 Trae 中使用

本仓库提供 [SKILL.md](SKILL.md)，可作为 Trae Skill 使用。将仓库放入项目的 `.trae/skills/image-to-perler`，或当前 Trae 版本支持的个人 skills 目录，按对应方式启用。

示例指令：

```text
使用 image-to-perler 将这张图片制作成 52×52 格拼豆图纸，
使用 Perler Midi 色板，最多保留 16 色。
保留透明区域，导出可编辑项目、离线 HTML 和用量清单。
```

需要 AI 重绘时，请明确提出。图片转换本身只进行缩放与颜色映射，不等同于 AI 像素画重绘。

npm run build      # 构建单文件离线工作台
